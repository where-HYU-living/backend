# 평면도 JSON (파일 하나 = 평면도 하나)

- 파일 이름은 `{id}.json`, 안의 `id` 와 같아야 한다. 서버가 뜰 때마다 읽어서 `floorplans` 테이블에 id 기준으로 덮어쓴다(파일을 지우면 테이블에서도 지워진다).
- 형식은 프론트 `src/api/types.ts` 의 `FloorPlan` 이다. 잘못된 파일이 있으면 어느 파일의 무엇이 문제인지 알려 주며 서버가 뜨지 않는다 (`FloorPlanValidator`).
- id 구간: **1~99 청년안심주택 / 101~199 매물(데모) / 201~299 기숙사**.
- 청년안심주택은 `floorplan-labels.json` 의 sha256 로 주택형에 자동 연결된다. 매물은 `listings.json` 의 `floorplanId`, 기숙사는 `dorms.json` 호실의 `floorplanId` 에 id 를 쓴다.
- `1.json`·`2.json`(청아진 18·18A)은 프론트 목업에서 옮긴 **임시본**이다. 이미지로 다시 만든 JSON 으로 덮어쓰면 된다.
